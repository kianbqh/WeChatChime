轻响 · WeChatChime v0.2.0
给重要的人，留一个特别的提示音。

适用于 Windows 10 / 11 x64。
最小化兼容模式目前适配微信 4.1.13.63。

开始使用

1. 解压到一个可写文件夹，双击 WeChatChime.exe。
2. 登录电脑版微信，置顶重点联系人的会话。
   在轻响中勾选“支持微信最小化（兼容模式）”，等待底部显示正在监听。
3. 点击“+ 添加”，选择近期会话或输入与微信一致的完整备注名。
   为联系人选择专属提示音，点击“试听”。
4. 保持微信最小化，等这位联系人发来一条新消息，确认提示音。
   关闭轻响窗口后，程序会继续留在系统托盘。

日常操作

• 单击托盘图标或再次打开程序，可以回到设置界面。
• 右键托盘图标选择“退出”，完全关闭轻响。
• “暂停提醒”控制全部联系人，也可以单独开关某位联系人的提醒。
• 连续消息间隔可设为 0–30 秒，默认 2 秒，同一联系人在间隔内只响一次。
• 内置 3 种短音，也支持 WAV / MP3 / M4A / WMA，单文件上限 20 MB。
  格式播放能力取决于 Windows 解码器，导入后建议试听一次。

联系人设置和导入音效自动保存在程序旁的 data 文件夹。
移动软件时一起带走即可。主程序约 70 KB，使用 Windows 自带的 .NET Framework 4.x。

使用提示

轻响根据会话未读数的增加触发声音，首次连接只记录已有未读。
正在阅读的聊天、未读数封顶、会话不在可读取列表中等情况，可能不会触发提醒。
建议置顶重点联系人；同名联系人请先设置不同备注名。

最小化兼容模式是针对特定微信版本的非官方适配，会在监听期间启用微信的辅助访问状态，
关闭兼容模式或正常退出时还原由轻响做出的修改。微信升级后可能需要更新适配。
遇到无法读取时，请查看窗口底部的状态说明；若提示还原失败，退出并重新打开微信即可。
