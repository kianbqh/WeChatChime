# 兼容性与实现说明

轻响通过 Windows UI Automation 获取微信会话快照，再根据未读数变化触发提示音。本文记录 v0.3.0 的适配方式和验证范围，方便排查问题或继续开发。

## 支持环境

| 项目 | 当前支持 |
| --- | --- |
| 系统 | Windows 10 / 11 x64 |
| 运行环境 | .NET Framework 4.x |
| 微信最小化适配 | 4.1.13.63 |
| 微信模块 | `Weixin.dll` |
| 模块 SHA-256 | `8bf9ae1edf52676bbfa2e0c4024af207c0f9bba589758f99de467515c90635e1` |

版本号和文件校验共同确定适配对象。微信升级后，如果底部提示版本不支持，可以在 [Issues](https://github.com/kianbqh/WeChatChime/issues) 提供微信版本和助手状态文字，方便继续适配。

## 会话快照与提醒

读取线程找到微信主窗口后，定位 `session_list`，批量缓存会话元素的名称、控件标识和类型。解析器从 `session_item_` 标识提取会话名称，并解析摘要行开头的未读计数。每轮正常读取后等待约 1.8 秒；读取不可用时改为 5 秒后重试。

提醒引擎保存每个会话上一次的未读数。只有名称匹配、规则开启、未读数增加且超过冷却时间，才发出音效请求。首次读取建立基线，避免启动时补响旧消息；修改音效或暂停设置不会清空已有基线。进程、进程创建时间或主窗口改变时重新建立基线。

UIA 只提供微信当时暴露的会话，因此建议先置顶重点联系人。没有未读变化的当前聊天、已经封顶的未读计数，以及暂未出现在可读取列表中的会话，都可能无法触发提醒。识别到同名会话后会暂停该名称的规则，可设置不同备注名后重新打开助手。

## 最小化兼容模式

当前适配通过微信进程内的一个辅助访问状态字节，让会话控件树保持可读取。该字节位于模块 RVA `0xAE2B0C8`，关联指令位于 RVA `0x839902`。

启用前会校验版本和文件散列、主窗口归属、进程创建时间、模块范围、运行时指令与内存页权限。校验通过后，将原始值 `0` 改为 `1` 并回读确认，在监听期间保持启用。这是针对特定版本的非官方适配，修改发生在进程内存中。

关闭兼容模式或正常退出时，通过保留的原进程句柄还原自身修改的状态；原本就是 `1` 的状态保持不变。工具被强制结束时可能无法完成还原，此时重启微信即可重新初始化状态。新下载的程序默认关闭兼容模式，由使用者在界面中开启。

### 状态重置与自动恢复

微信运行期间可能把辅助访问状态重新设为 `0`。v0.3.0 在 UIA 查询前定期检查状态，重新验证进程身份、内存页及运行时指令后将已知的 `0` 恢复为 `1`，无需手动关闭再开启兼容模式。健康目标约每 5 秒复查，校验失败的目标间隔 30 秒重试；重试按窗口、进程 ID 和创建时间分别记录，新目标可以立即检查。

恢复仍遵循原有所有权规则：预先启用的 `1` 不归轻响所有；如果它后来变成 `0`，轻响再次启用时才取得这一修改的所有权，退出时恢复为 `0`。遇到未知状态值或校验失败，不覆盖目标。短暂的读取中断保留未读基线，同一来源恢复后按未读净增提醒；微信进程或窗口更换后重新建立静默基线。

## 内置音效

8 种内置音效均按需合成为 22,050 Hz、单声道、16-bit PCM WAV，不随程序携带音频资源。时长为 1.1–2.8 秒，使用淡入淡出和有余量的混音；一次生成的 PCM 最大约 121 KiB。轻柔双音保持舒缓的双音结构，醒目连响使用三组双音，雷达呼叫使用重复扫频，方便按场景选择。

## 本地验证

`test.ps1` 的 523 项检查通过：配置与音效 204 项、消息解析与提醒规则 54 项、兼容校验与生命周期 73 项、原生界面交互及布局 192 项。兼容校验使用测试数据，不操作真实微信；UI 检查包括程序化的 125% / 150% 缩放。新增回归覆盖重复状态重置、预先启用的状态、部分写入回滚、独立重试时序、读取中断后的提醒基线，以及音效电平、持续时间与淡入淡出。

在微信 4.1.13.63 上，v0.3.0 的实机测试保持微信最小化，主动模拟 3 次已持有兼容状态的重置，分别在 7.06、6.99、6.94 秒内自动恢复。40.73 秒内收到 18 次状态快照，恢复后均可读取 9 个会话；关闭模式后回读确认状态还原为 `0`。此测试不发送消息或播放音效，验证的是实际后台读取和恢复链路。

v0.2.0 已验证助手收进托盘后继续读取、重复启动恢复窗口和正常退出还原。真实联系人来信到指定音效的完整收信测试，以及微信重新登录、长期运行和实际系统 DPI，仍需更多使用验证。

v0.3.0 主程序为 74,752 字节。此前 v0.2.0 一次 50 秒空规则运行样本的 Working Set 约 58–63 MB，累计 CPU 时间约 0.28 秒；该样本开启了最小化兼容，未播放音频。资源占用会随运行时间、会话数量和系统环境变化。
